# Cyberpunk HUD для OpenCode

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
![OpenCode](https://img.shields.io/badge/OpenCode-2.2.x-ff8a00)

Неоновая тема, анимированные статус-бейджи и интерактивный экран `/deck` в стиле
mission control для TUI [OpenCode](https://opencode.ai).

`/deck` показывает сессии и их состояние в реальном времени, запросы, которым нужно ваше
внимание, дерево проекта, системную телеметрию и траты — всё прямо в терминале, с braille-кубом
и радаром в свободном месте.

> **Статус:** ранняя экспериментальная версия. Проверено на OpenCode 2.2.1 и
> `@opencode/plugin` 2.2.5. TUI-API молодой — фиксируйте версию OpenCode, если нужна
> долгосрочная стабильность.

[English version](README.md)

## Возможности

- **Две темы** — `cyberpunk` (оранжевая) и `cyberpunk-violet`.
- **HUD-бейджи** — анимированные статусы в футере home и prompt.
- **Панель сессий** — root-сессии от новых к старым, живой спиннер работы модели, мигающий
  индикатор запросов разрешений/инбокса, превью последних сообщений, id и стоимость.
- **Работа с вниманием** — `a` переходит к следующей сессии, ждущей действия; заголовок и
  телеметрия показывают количество запросов.
- **Дерево проекта** — только папки, раскрытие/сворачивание, braille-радар в свободных строках.
- **Системная панель** — хост, ядро, uptime, shell, версии Node/OpenCode, спарклайны памяти и
  CPU, вращающийся каркасный куб с орбитальными частицами, осциллограмма и hex-поток.
- **Телеметрия** — часы, load average, IPv4, диск, батарея, запущенные/всего сессий, ожидающие
  запросы и суммарные траты.
- **Переключатель анимации** — `/cyberhud` или `m` замораживает всё движение.
- **Без подпроцессов** — ничего не запускается через shell, поэтому stderr внешних утилит не
  может испортить TUI.

## Требования

- **OpenCode 2.2.x** с TUI plugin API (проверено на 2.2.1).
- **npm или Bun** для установки зависимостей плагина.
- Терминал с **truecolor** и поддержкой **Unicode braille** (Kitty, WezTerm, Ghostty, Alacritty,
  iTerm2, Windows Terminal и т. п.). Nerd Font не нужен.
- Комфортно около **100×32**. При меньшей ширине колонка телеметрии и радар скрываются, а не
  ломают вёрстку.

Основная целевая платформа — Linux. macOS работает для основного UI; Windows не тестировался
(батарея и диск могут отсутствовать, остальное деградирует мягко).

## Установка

### 1. Клонируйте плагин

```bash
git clone https://github.com/your-name/opencode-cyberpunk-hud.git \
  ~/.config/opencode/plugins/cyberpunk-hud

cd ~/.config/opencode/plugins/cyberpunk-hud
npm install --omit=dev
```

`node_modules/` должен остаться на месте: во время работы плагин ищет `@opencode/plugin/tui`,
`@opentui/core` и `solid-js` в собственной папке.

Для разработки можно держать checkout в другом месте и сделать симлинк:

```bash
git clone https://github.com/your-name/opencode-cyberpunk-hud.git ~/src/opencode-cyberpunk-hud
cd ~/src/opencode-cyberpunk-hud && npm install
ln -s ~/src/opencode-cyberpunk-hud ~/.config/opencode/plugins/cyberpunk-hud
```

### 2. Установите темы (необязательно)

```bash
mkdir -p ~/.config/opencode/themes
cp themes/cyberpunk.json themes/cyberpunk-violet.json ~/.config/opencode/themes/
```

Плагин использует семантические токены активной темы, поэтому работает и с другими темами.
Эти две — задуманный вид.

### 3. Зарегистрируйте плагин

Добавьте плагин (и при желании тему) в `~/.config/opencode/cli.json`:

```json
{
  "$schema": "https://opencode.ai/v2/cli.json",
  "theme": {
    "mode": "dark",
    "name": "cyberpunk"
  },
  "plugins": ["./plugins/cyberpunk-hud"]
}
```

Минимальный пример лежит в [`examples/cli.json`](examples/cli.json).

### 4. Перезапустите OpenCode

Откройте палитру команд и выберите **Open cyberdeck** или введите `/deck`.

## Использование

| Команда | Действие |
| --- | --- |
| `/deck` | Открыть панель CYBERDECK |
| `/cyberhud` | Включить/выключить анимацию |

Обе команды доступны и в палитре команд (**Open cyberdeck**, **Toggle cyberpunk motion**).

### Управление в деке

| Клавиша | Действие |
| --- | --- |
| `up` / `k` | Предыдущая сессия (или строка дерева в фокусе PROJECT) |
| `down` / `j` | Следующая сессия (или строка дерева в фокусе PROJECT) |
| `return` | Открыть сессию (или раскрыть/свернуть папку) |
| `tab` | Переключить фокус между сессиями и деревом |
| `a` | Перейти к следующей сессии, ждущей внимания |
| `n` | Создать сессию и открыть её |
| `r` | Обновить список сессий |
| `m` | Включить/выключить анимацию |
| `escape` / `q` | Вернуться на home (OpenCode продолжает работать) |

### Список сессий

- Только root-сессии: дочерние subagent-сессии и архив скрыты.
- `⠋⠙⠹…` — модель работает в этой сессии прямо сейчас.
- Мигающий красный `!` — ждёт запрос разрешения или элемент инбокса; строка подсвечивается
  красным.
- Заголовок блока становится `SESSIONS · N NEED YOU`, если что-то ждёт.
- Две строки превью показывают последнее сообщение пользователя и последний ответ ассистента,
  затем id, стоимость и число ожидающих запросов.
- Состояние запросов обновляется раз в 5 секунд для видимых строк.

### Дерево проекта

- Только папки, два уровня; скрытые папки и каталоги сборки пропускаются
  (`node_modules`, `.git`, `dist`, `build`, `target`, `.next`, `.opencode`).
- `▸` свёрнуто, `▾` раскрыто, `·` лист.
- В свободных строках под деревом крутится braille-радар. Если дерево занимает всю панель, радар
  скрывается, чтобы ничего не обрезалось.

### Системная панель

- Данные из Node `os`: хост, ядро, uptime, shell, версии Node/OpenCode, память, CPU, pid/cwd,
  плюс 24-точечные спарклайны памяти и CPU раз в секунду.
- Вращающийся braille-куб с тремя орбитальными шлейфами частиц.
- Под кубом — осциллограмма `SIG` и бегущий `HEX`-поток.
- Сбоку от куба (если панель достаточно широкая): часы с мигающим двоеточием, load average,
  IPv4-интерфейс/адрес, диск, батарея, запущенные/всего сессий, ожидающие запросы и суммарные
  траты по root-сессиям.

### Темы

| Тема | Акцент |
| --- | --- |
| `cyberpunk` | оранжевый `#ff8a00` |
| `cyberpunk-violet` | фиолетовый `#c77dff` |

Обе темы построены на семантических токенах OpenCode, поэтому диффы, markdown, подсветка
синтаксиса и цвета обратной связи остаются согласованными.

## Как это устроено

- **Без JSX.** OpenCode 2.2.x ищет `solid-js` в `node_modules` плагина при запросе JSX-рантайма,
  но вложенные пакеты отклоняются — появляется `Cannot find package 'solid-js'`. Плагин собирает
  `BoxRenderable` и `TextRenderable` из `@opentui/core` напрямую.
- **Новое дерево renderable на каждый рендер.** OpenTUI освобождает нативные Yoga-узлы при уходе
  с маршрута; повторное использование старого дерева роняет второй заход в `/deck`.
- **Braille-рендеринг.** Куб и радар используют сетку 2×4 субпикселя на символ (в 8 раз выше
  разрешения обычной ячейки), генерируются чистыми функциями и пишутся в один `TextRenderable`.
- **Состояние вне компонента.** Флаг открытия, выбор, прокрутка и режим анимации живут в
  `storage.memory("cyberdeck", …)` и переживают hot reload плагина.
- **Пауза означает паузу.** `m` отключает все таймеры анимации: куб, радар, сканеры, спиннеры и
  бегущую строку.
- **Без shell-вызовов.** Только Node API, чтение файлов из `/sys` и контекст плагина OpenCode.
  Падающая внешняя утилита вроде `fastfetch` может писать stderr в TUI и ломать экран.

### Источники данных

| Данные | Источник |
| --- | --- |
| Сессии, превью, стоимость | `context.data.session.*` |
| Ожидающие запросы | `context.data.session.permission.list` / `pending.list` |
| Папки проекта | `fs.readdirSync` по текущей локации |
| Память / CPU / load / сеть | Node `os` |
| Диск | `fs.statfsSync` |
| Батарея | `/sys/class/power_supply/*` |

Ничего не отправляется по сети и не покидает машину.

## Диагностика

| Симптом | Решение |
| --- | --- |
| Плагин не загружается | Проверьте `~/.local/share/opencode/log/opencode.log` на `plugin operation failed` и наличие `node_modules/` (`npm install --omit=dev`). |
| `Cannot find package 'solid-js'` | Не добавляйте JSX; используйте renderable из `@opentui/core`, как в этом репозитории. |
| Тема не найдена | Скопируйте JSON в `~/.config/opencode/themes/` и перезапустите OpenCode. |
| Нет колонки телеметрии | Расширьте терминал: она появляется при ширине панели SYSTEM не менее 40 символов. |
| Нет радара | Сверните папки или увеличьте высоту: радару нужно 5 свободных строк. |
| Нет строки батареи | У десктопов и части VM нет `/sys/class/power_supply`; строка просто не выводится. |
| Анимация мешает | Нажмите `m` в `/deck` или выполните `/cyberhud`. |

## Разработка

```bash
npm install          # включая TypeScript и типы Node
npm run typecheck    # tsc --noEmit, используется и в CI
```

Автотестов рантайма пока нет (TUI требует интерактивного терминала). Ручной чек-лист перед
релизом:

1. `/deck` открывается; `escape` возвращает home, не закрывая OpenCode.
2. Открыть `/deck` второй раз — не должно быть падения.
3. Список обновляется; `enter` открывает выбранную сессию.
4. `tab` фокусирует дерево; `enter` раскрывает/сворачивает папки; радар скрывается при нехватке
   места.
5. `n` создаёт сессию; `a` находит сессию с ожидающим запросом.
6. `m` замораживает все анимации.
7. Узкое окно — нет поломок вёрстки и обрезанных рамок.

Весь плагин — один файл [`tui.tsx`](tui.tsx): braille/ASCII-рендереры → инициализация плагина →
состояние → данные сессий → раскладка дека → keymap → таймеры.
